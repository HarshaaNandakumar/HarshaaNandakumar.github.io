# harshaanandakumar.github.io

Personal portfolio — live at **[harshaanandakumar.github.io](https://harshaanandakumar.github.io)**.

Single-page editorial site showcasing supply chain analytics and business development work. Built with vanilla HTML + CSS, no frameworks, no build step.

## Stack

- Plain HTML5 + CSS (all inline in `index.html`)
- Google Fonts: Fraunces, Outfit, JetBrains Mono
- Zero JavaScript dependencies (one tiny IntersectionObserver for reveal animations)

## Editing

Just open `index.html` and edit. Commit and push — GitHub Pages redeploys automatically within a minute.

## Sections

1. Hero
2. Contents
3. About + impact stats
4. Selected Work (5 case studies)
5. Capabilities
6. Experience
