02 · Selected Work

Five case studies spanning automation, dashboard design, SQL reporting, and network analysis — each with a problem statement, approach, and measurable outcome.

001

Freight Quote Automation

A multi-mode VBA tool that generates standardized freight quotes across seven modes — sea import/export (FCL/LCL/multi-drop), air import/export, and domestic. Sequential quote IDs, an automatic audit log, and one-click PDF export to cloud storage replace a manual, error-prone workflow.

VBA Excel Automation
Case Study
002

Logistics Ops Excellence

A connected three-part operational governance system: a 25-field Daily Shipment Report with Incoterms validation, an Account Management phase tracker with status and owner assignments, and a daily team huddle tracker with MoM minutes, desk-level file counts, and monthly rollups.

Excel Power Query Process Design
Case Study
003

Freight Pipeline Dashboards

Two Power BI dashboards built for freight forwarding. The Revenue/GP dashboard segments performance by commercial vs non-commercial with per-employee drilldown. The Sales Pipeline dashboard tracks revenue by vertical, lane-wise volume, customer concentration, and a converted / quoted / nominated funnel.

Power BI DAX Data Modeling
Case Study
004

Freight Lane Network Analysis

A network-theoretic view of a freight forwarding branch's lane portfolio. Models lanes as a directed graph in NetworkX, computes hub centrality and path analysis, and surfaces structural fragility through a three-factor scoring model — blast radius, failure probability, and redundancy. Reveals risks invisible in a tabular view.

Python NetworkX pandas
Case Study
005

SQL Logistics Reporting Pack

A curated library of ten SQL queries covering the reporting scenarios every supply chain analyst encounters — customer revenue ranking, lane performance, OTIF, shipment aging, monthly trends, top-N per vertical, running totals, customer concentration (Pareto), and a tiered health dashboard. Each query paired with an analyst interpretation of its output.

SQL SQLite PostgreSQL
